## Organization

```ts
{
  _id: ObjectId,
  name: string,
  orgType: "gas" | "school" | "corporate" | "generic",  // for future vertical routing, unused in Phase 0
  createdAt: Date,
  isActive: boolean
}
```

## User (Super Admin / Org Admin / Manager)

```ts
{
  _id: ObjectId,
  organizationId: ObjectId | null,  // null for super_admin; required for org_admin and manager
  name: string,
  email: string,
  passwordHash: string,
  role: "super_admin" | "org_admin" | "manager",
  createdAt: Date
}
```

`manager` is in the schema and JWT union so Phase 2 needs no migration.
Phase 1 / Stabilize Web only issue `super_admin` and `org_admin` tokens.

## Driver Trip View (GET /api/trips/my, GET /api/trips/my/:id)

Authenticated driver JWT only (`role: driver`, `userId` = driver `_id`).
Returns assigned trips with route/vehicle so the app does not list the
whole org. Open trips (`scheduled`, `in_progress`) plus completed trips
from the last 14 days.

```ts
{
  _id: ObjectId,
  status: "scheduled" | "in_progress" | "completed",
  scheduledAt: Date,
  startedAt: Date | null,
  endedAt: Date | null,
  lastKnownLocation: { lat: number; lng: number; updatedAt: Date } | null,
  currentStopIndex: number,
  route: {
    _id: ObjectId,
    name: string,
    stops: { order: number; label: string; lat: number; lng: number }[],
    roadPath: [{ lat: number; lng: number }] | null
  },
  vehicle: { vehicleNumber: string }
}
```

Drivers cannot `GET /api/trips` (org list) or `POST /api/trips`.
`GET/PATCH` a trip by id is allowed only when `trip.driverId` matches
the JWT `userId`.

## Public Trip View (GET /api/public/trips/:token — no auth)

Read-only payload for the public tracking page. Token is the only credential.
Includes route/vehicle/driver display fields so the page never calls org-scoped APIs.

```ts
{
  _id: ObjectId,
  status: "scheduled" | "in_progress" | "completed",
  scheduledAt: Date,
  startedAt: Date | null,
  endedAt: Date | null,
  lastKnownLocation: { lat: number, lng: number, updatedAt: Date } | null,
  currentStopIndex: number,
  route: {
    name: string,
    stops: { order: number, label: string, lat: number, lng: number }[],
    roadPath: [{ lat: number, lng: number }] | null
  },
  vehicle: { vehicleNumber: string },
  driver: { name: string }
}
```

## Socket.IO Event Payloads

```ts
// Client -> Server
"trip:join"          { tripId: string }
"trip:leave"         { tripId: string }
"location:update"    { tripId: string, lat: number, lng: number, timestamp: string, speed?: number }
"stop:reached"       { tripId: string, stopIndex: number }

// Server -> Client
"location:broadcast" { tripId: string, driverId: string, lat: number, lng: number, timestamp: string }
"trip:status_changed"{ tripId: string, status: "scheduled" | "in_progress" | "completed" }
"stop:reached_broadcast" { tripId: string, stopIndex: number }

```
