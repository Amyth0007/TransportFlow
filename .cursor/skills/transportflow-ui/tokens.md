## Type

- Display: **Syne** (800) — product name, page titles
- UI: **DM Sans** (400/500/600) — everything else
- Radius: 14px cards, 10px controls, 999px badges
- Map polyline: cyan `#2ee6d6`, weight 5

## Motion

- Page enter: 420ms ease, fade + 8px rise
- Live badge: 1.8s pulse on cyan glow
- Buttons: 150ms background/transform
- Sidebar active: 1px cyan left bar
